## 3. 身份与职业｜Statuts et métiers


| 日文           | 罗马音       | 中文        | Français                            |
| ------------ | --------- | --------- | ----------------------------------- |
| 先生（せんせい）     | sensei    | 老师（称呼、尊称） | professeur (titre ou appellation)   |
| 教師（きょうし）     | kyōshi    | 教师（职业）    | enseignant(e) (métier)              |
| 学生（がくせい）     | gakusei   | 学生        | étudiant(e)                         |
| 会社（かいしゃ）     | kaisha    | 公司        | entreprise                          |
| 会社員（かいしゃいん）  | kaishain  | 公司职员      | employé(e) d’entreprise             |
| 社員（しゃいん）     | shain     | 公司员工      | salarié(e), membre d’une entreprise |
| 銀行（ぎんこう）     | ginkō     | 银行        | banque                              |
| 銀行員（ぎんこういん）  | ginkōin   | 银行职员      | employé(e) de banque                |
| 医者（いしゃ）      | isha      | 医生        | médecin                             |
| 研究者（けんきゅうしゃ） | kenkyūsha | 研究人员      | chercheur / chercheuse              |
| エンジニア        | enjinia   | 工程师       | ingénieur(e)                        |


> 💡 「会社員」和「社員」都是正确词语：前者明确指公司职员，后者指公司员工或成员。｜「会社員」et「社員」sont tous les deux corrects : le premier désigne explicitement un employé d’entreprise, le second un salarié ou membre de l’entreprise.
