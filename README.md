## 🧭 学习路线｜Parcours

建议按下面的顺序学习：

1. **先认字｜Commencer par les kana**：掌握平假名、片假名和基础发音。
2. **会介绍自己｜Se présenter**：姓名、国籍、来源、职业，以及助词「も」。
3. **会介绍别人｜Présenter quelqu’un**：第三人称、肯定与否定回答、请求重复。
4. **扩展数字｜Étendre les nombres**：数字 1–100 与年龄表达。
5. **循环复习｜Réviser en boucle**：结合词汇表，把句型读出来、写出来、用出来。

## ✨ 你会学到什么｜Ce que vous allez apprendre

- 读写 **46 个基础假名**，区分平假名与片假名。
- 认识浊音、半浊音、拗音、小「っ」、长音和拨音「ん」。
- 使用「わたしは…です」介绍自己。
- 询问姓名、国籍、职业和来源。
- 用「彼／彼女は…です」介绍他人。
- 掌握礼貌的肯定、否定和“请再说一遍／请写下来”等课堂表达。
- 读懂 1–100 的数字构成，并表达年龄。

## 📝 推荐学习方法｜Méthode conseillée

每次学习可以用 15–20 分钟完成一个小循环：

1. **看｜Lire**：先看日文，再看罗马音，最后核对中文或法语。
2. **读｜Prononcer**：遮住翻译，朗读每个句型三遍。
3. **写｜Écrire**：抄写关键词，并替换句中的 `〇〇`。
4. **回忆｜Rappeler**：不看笔记，尝试完成一次问答或自我介绍。
5. **复习｜Réviser**：把不熟的词加入下一次复习，而不是一次记完所有词。

### 🎤 第一个可复用成果｜Premier résultat réutilisable

完成第一课后，你可以练习下面这段自我介绍：

> **はじめまして。わたしは〇〇です。中国人です。上海から来ました。学生です。どうぞよろしくお願いします。**  
> *Hajimemashite. Watashi wa 〇〇 desu. Chūgoku-jin desu. Shanhai kara kimashita. Gakusei desu. Dōzo yoroshiku onegaishimasu.*  
> **中文：** 初次见面。我叫〇〇，是中国人，来自上海，是一名学生。请多关照。  
> **Français :** Enchanté(e). Je m’appelle 〇〇. Je suis étudiant(e) chinois(e) et je viens de Shanghai. Au plaisir de faire votre connaissance.
